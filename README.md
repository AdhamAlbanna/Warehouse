# Warehouse

An iOS app written in **Swift 5** for keeping track of the things you store: each item is saved with a name, a date and a photo, and grouped by storage type.

## Features
- Add, edit and delete items
- Input validation with friendly alerts
- Attach a photo to each item from the photo library
- Organize items by storage type (create your own types)
- Live list updates with `NSFetchedResultsController`
- Fully offline: all data is stored on the device with **Core Data**

## Tech
- Swift 5, UIKit, Storyboards
- Core Data (`Items` and `StoredType` entities)
- `UIImagePickerController` and `UIPickerView`

## Run it
1. Clone the repository
2. Open `Warehouse.xcodeproj` in Xcode
3. Choose a simulator or device and press **Run**
